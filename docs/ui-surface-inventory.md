# Chloe UI Surface Inventory

The browser app is a single document at `/vault/index.html`, not a multi-route SPA. Major surfaces are a mix of the welcome/chat stage, a responsive conversation drawer, side sheets, one confirmation dialog, popovers, and callback-driven runtime content. This inventory follows the current DOM and click wiring in `web/index.html`, `web/app-workspace-20260916-r3.js`, `web/profile-overview.js`, `web/customer-devices.js`, and `web/browser-bridge.js`.

The capture runner uses local Playwright API fixtures and `window.DropVault` callbacks. It does not connect to production. Per-scene fixture markers, viewport/theme, browser errors, missing static resources, layout samples, and screenshots are stored in `tests/artifacts/chloe-system/<prefix>/audit.json`; the filtered gallery is beside it. The run-specific results and actual stylesheet availability/order are written to [ui-audit-report.md](ui-audit-report.md).

## Stylesheet Cascade

`web/index.html` owns the stylesheet order. The machine report lists every stylesheet URL in exact document order and confirms whether the corresponding local file exists. In broad terms, the cascade starts with `styles.css`, applies legacy quota/composer/dialog and chat rules, then feature styles for approvals, models, artifacts, devices, and the workspace, and ends with `browser-chatgpt.css`, `component-interactions.css`, `profile-overview.css`, `ui-system.css`, and `chloe-autumn.css`. CSS in this app relies on later-file overrides, so the exact tail order is material to visual results.

## Coverage Boundaries

All screenshots use explicitly labelled synthetic fixtures and callbacks. They prove client rendering and responsive presentation, not live provider data, OAuth, native credential storage, real devices, server reachability, or destructive/privileged actions. The runner never confirms an archive, approval, invitation, device disable, remote workspace creation, account login, or deployment. Missing assets fail as HTTP 404 and are recorded; they are not replaced with empty CSS, HTML, or image bodies. The current requested background is read from `web/assets/chloe-autumn-landscape.webp`, and the capture records its decode dimensions.
